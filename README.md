# Cantor Algebra 3D Model
Designs and sketches for bringing the Cantor algebra to live by 3D printing a model and then creating a metal sculpture.

The Cantor set is the (uncountable) Stone space dual to the (countable) [Cantor algebra](https://en.wikipedia.org/wiki/Cantor_algebra).

## status

- wrote math paper, Lean code constructing the Cantor algebra explicitly
- designed 3D model in Rhino of Cantor set
- printed 3D models of Cantor set
- on display at MICA until 5/17/2026

## future directions

- extend 3D model to have more branches
- turn 3D printed model into larger, metal sculpture
- include binary tree above metal sculpture
- include "skirt" or "drape" dropping below end leaf/node of binary tree to represent cylinder set in Cantor algebra
- optional: use lights to indicate different cylinder sets
